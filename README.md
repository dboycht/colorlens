# 辨色助手 · colorlens

一个给**色盲 / 色弱**人士用的 Android 辅助工具。

拍照（或从相册选一张）→ 手指点你想问的位置 → 手机告诉你**这是什么颜色**，并且说清**你的眼睛和别人的眼睛差在哪**。

> 目标不是「告诉你颜色的客观数值」，而是**在你看不出颜色差别的时候，给你一条能用的线索**。

---

## 功能

| 页面 | 做什么 |
| --- | --- |
| **拍照** | 应用内相机（CameraX），也可以从相册选一张。闪光灯可开 |
| **取色** | 拖动或点按照片上的任意位置，上方浮出放大镜（免得手指挡住要取的点），下面用大字给出色名 |
| **对比** | 取 A、B 两个点，回答「这两个颜色我分得出来吗」——同时给出**常人看到的**、**你看到的**，以及你能靠什么分辨 |
| **模拟** | 同一张照片「你的视角 / 常人的视角」一键对照，程度可调 |
| **设置** | 8 种色觉类型、模拟程度、语音播报（详/简）、大字号、高对比、对比灵敏度 |

- **语音播报**：取色和结论都能念出来 —— 拿着东西、单手操作、或者不方便看屏幕时用得上。
- **大字号 / 高对比**：为低视力与对比敏感度下降的人准备（高对比是纯黑背景 + 纯白文字）。
- **色名分两层**：基本色名（红、橙、黄、黄绿、绿、青绿、天蓝、蓝、紫、品红、粉、棕、米、灰、白、黑）可以直接说出口；次基本色名（朱红、酒红、藏青、墨绿…）只作为「更像 X」的补充。词表依据见下。

## 三条设计底线

1. **不联网、不上传、不落盘。** 照片只在内存里，关掉应用就没了；没有账号、没有历史记录、不要存储权限（相册走系统照片选择器，只拿到你选的那一张）。
2. **说的是「你的眼睛」，不是「颜色的客观差别」。** 红绿色盲看红与绿并**不觉得它们相近**（红暗、绿亮），所以「差别很明显」这句客观描述对他是错的。判定必须同时给出常人看到的、你看到的、以及你能靠什么线索。
3. **不确定就说不确定。** 模拟是人群平均，不是诊断；蓝色觉异常的模型精度差，界面上直说。**这不是医疗器械。**

## 怎么判断「两个颜色分不分得出来」

色差用 [OKLab](https://bottosson.github.io/posts/oklab/)（Ottosson, 2020）的感知距离，`0.02` 约等于刚好能分辨。但**只看色差是不够的**，因为对色觉异常者来说"能分开"和"看得出颜色种类"是两件事：两个颜色可能因为一明一暗而分得开，可色相信息已经没了。

所以判定同时看三件事：**常人看到的色差**、**你看到的色差**、以及**色相是否塌陷**。色相塌陷用三条判据取或：幅度塌陷、色相角塌陷、**色名家族塌陷**（例如常人看是「灰棕」和「灰橙」，你看到的都是「暗黄」）。

## 色觉模拟怎么算

矩阵取自 **Machado, Oliveira & Fernandes (2009)**, *A Physiologically-based Model for Simulation of Color Vision Deficiency*（IEEE TVCG 15(6)），3 类（protan / deutan / tritan）× 11 档，中间档按论文在相邻两档之间线性插值。

两个实现要点，错了结果就不对：

- 矩阵必须作用在**解码后的线性 RGB** 上（跳过 gamma 解码是最常见的错误：`#FF0000` 的绿色盲结果会变成 `#5E4700` 而不是正确的 `#A39000`）。
- 全色盲**不在**该表里（论文只有三列），本项目用线性光亮度做灰度。
- ⚠️ 该模型对**蓝色觉异常（tritan）**的可靠度较低，界面上已标注仅供参考。

管线正确性用独立实现公开印出的输入输出对钉住：`deuteranopia(#FF0000) = #A39000`、`deuteranopia(#00FF00) = #EFD63A`（colorspace 包文档中的结果）。

## 色名依据

- **基本色名**：汉语基本颜色词，另加日常高频的 黄绿 / 青绿 / 天蓝。参考 李红印《现代汉语颜色词语义分析》(2001) 与 Sun & Chen (2018, PLoS ONE)：汉语的颜色范畴与英语十一色相当，但同一范畴内不同人用的词不一样，所以本应用每个范畴只收敛到一个最通用的词。**青**不作独立色名（绿、蓝合称，且古汉语中「青丝」指黑发），青系一律报「青绿」。
- **次基本色名**：只作为「更像 X」的提示，不单独使用；描述类词（藕荷、绛紫、月白…）刻意不用，因为听话人常常不共享这些词。
- **原型色值**只取两个可引用来源：W3C CSS Color Module Level 4 具名色，与中国色名录（其页面注明取自中科院《色谱》1957）。原型取**中间调**而非纯色——用纯红作「红」会让暗红被判成棕。
- 家族（色相名）**由色相角决定**，明度与彩度只决定修饰词（浅/深/暗/亮/鲜/灰/淡）。

## 构建

需要 Android SDK（compileSdk 36）与 JDK 17+。

```bash
./gradlew testDebugUnitTest assembleDebug
```

单元测试是纯 JVM 的，不需要设备；其中两个「目检报告」测试会把色名表与对比表输出成文本 / SVG 到 `app/build/reports/colorlens/`。

## 技术栈

Kotlin + Jetpack Compose（Material 3）· 单 Activity、底部五个分页 · CameraX · `minSdk 28` / `targetSdk 36` · 无第三方网络依赖、无分析 SDK。

刻意没有包含 `material-icons-extended`（单独就给 APK 加约 40 MB，界面图标用字形绘制）。
